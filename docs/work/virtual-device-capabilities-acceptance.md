## Delivery and physical qualification gates

- **Software implementation evidence:** focused suites above provide offline behavioral evidence. The merged baseline `10e9c206d68f12966d5bb7d5a0777ed5f0f26a3c` (composed tree `f84be26b257ad225c0cd6816a428da2059e252da`) passed 15 hosted checks and CodeRabbit review before PR #1443 merge, as recorded in the epic.
- **Still-open completion work:** #1421 remains open for explicit freshness presentation and convergence evidence; #1422 remains open for the composed acceptance inventory and documentation. Protocol/evidence PR #1424 has green current-head CI but its CodeRabbit review is rate-limited and scheduled once. Draft PR #1444 has local test evidence only; no current hosted CI or review result is established here. Therefore this ledger does not assert all delivery gates passed or the epic is complete.
- **Shelly helper provenance:** a native Celsius helper and raw voltage are separate qualified software sources. Runtime guard tests cover “uses a qualified native Celsius helper and revokes admission after helper configuration changes” and “converts raw NTC voltage using supplied calibration and rejects invalid electrical readings” in [guard candidate tests](../../apps/backend/src/plugins/devices-shelly-ng/services/shelly-guard-candidate.spec.ts). The actual supplied Plus 1PM Gen2 currently exposes `voltmeter:100` voltage; the installed script only logs its computed Celsius. Native helper ingestion on a physical device is not demonstrated.
- **Hardware commissioning:** no relay command, script installation, writer-isolation check, floor calibration, restart-bound measurement, endpoint-authentication qualification, independent protection proof, or physical OFF acceptance is claimed. The pilot commissioning record is [here](./virtual-thermostat/shelly-commissioning.md). The user identified the pilot as an electric heating mat under bathroom ceramic tiles. The proposed 30°C probe cutoff with 2 K recovery hysteresis is a draft for that site only, unverified and not a universal setting. Future activation remains gated on site-specific equipment qualification and commissioning; independent non-heating virtual devices can be delivered without representing the thermostat as commissioned.
